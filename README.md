# 프로젝트 별 (Project Star)

> "소통은 이해와 같지 않다"

React 기반 내러티브 어드벤처 게임

## 🎮 게임 소개

**프로젝트 별**은 자폐 스펙트럼 장애를 가진 딸 '별이'와 그녀의 어머니가 115층 수직 도시 '천층시'를 탈출하는 이야기를 담은 내러티브 어드벤처 게임입니다.

- **장르**: 내러티브 어드벤처 / 퍼즐
- **플랫폼**: 웹 (React)
- **예상 플레이 타임**: 25-40분
- **핵심 메시지**: 완벽한 이해 없이도 사랑은 전달될 수 있다

## 🌟 주요 특징

### 이중 시점 시스템
- **어머니 시점**: 딸을 보호하며 장애물을 제거하고 탈출 경로를 찾음
- **별이 시점**: 같은 장면을 감각 과민과 패턴 인식의 관점으로 경험

### 핵심 게임플레이 메커니즘

1. **손잡기/놓기 시스템**
   - 스페이스바로 손잡기 토글
   - 손을 잡으면: 별이 안정도 증가, 이동 속도 감소
   - 손을 놓으면: 별이가 패턴 관찰 가능, 안정도 서서히 감소

2. **안정도 시스템**
   - 환경의 소음, 빛, 군중 밀도가 별이의 안정도에 영향
   - 안정도가 낮으면 감각 과부하 상태 발생
   - 실시간 안정도 게이지로 상태 확인

3. **소음 제거 퍼즐**
   - 소음원을 찾아 비활성화
   - 별이의 스트레스를 줄여 다음 구역으로 진행

4. **패턴 관찰**
   - 별이는 패턴을 빠르게 인식
   - 발견한 패턴을 활용해 퍼즐 해결

## 🎯 게임 조작법

- **이동**: 방향키 또는 WASD
- **손잡기/놓기**: 스페이스바
- **소음원 비활성화**: 마우스 클릭
- **대화 진행**: 마우스 클릭

## 📖 스토리

### 세계관: 천층시(千層市)

115층 규모의 수직 도시에서 사회적 서열이 층수로 구분되는 디스토피아 사회. 능력주의와 효율성이 극단화되어 하층으로 갈수록 소음, 오염, 감시가 심화됨.

### 줄거리

어머니는 중증 자폐 스펙트럼 장애를 가진 딸 '별이'와 함께 지하 격리구역에 살고 있다. 어느 날, "적응 시설 강제 격리" 공문이 도착한다. 이는 사실상 영구 분리를 의미한다.

전직 구조대원 출신인 어머니는 결단을 내린다: **딸과 함께 115층 마천루로 탈출**하기로.

게임은 두 개의 시점으로 진행되며, 클라이맥스에서 감동적인 반전이 펼쳐진다.

## 🎓 교육적 가치

이 게임은 자폐 스펙트럼에 대한 이해를 높이고자 합니다:

1. **병리적 관점 거부**: 별이는 "고쳐야 할" 존재가 아님
2. **다양한 인지 스타일 존중**: 패턴 인식과 감각 처리의 차이를 강점으로도 표현
3. **비언어적 소통의 가치**: 손잡기, 리듬, 행동을 통한 연결 강조
4. **실제 경험 기반**: 감각 과부하, 예측 가능성 선호 등 실제 특성 반영
